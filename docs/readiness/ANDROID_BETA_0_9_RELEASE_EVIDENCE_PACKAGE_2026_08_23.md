## Blockers (named exactly, not glossed over)

1. **No local Android SDK/Gradle/Java toolchain in this environment** — blocks any real unsigned or
   signed APK build. Point of truth: CI (`mobile-capacitor.yml` per the July 27 kanban doc).
2. **No local Xcode toolchain** — blocks any iOS build entirely; iOS is explicitly out of scope for
   this Android-focused sprint regardless.
3. **No Android release signing keystore or `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON` in this environment**
   — blocks a real signed store release build, confirmed by the exact `--mode=release` FAIL list
   above. Matches the already-documented store-credentials blocker chain.
4. **No local Android emulator/device** — blocks visual confirmation of icon/splash/status bar
   rendering, live keyboard-open behavior, and the Android back-button behavior this sprint
   implemented (unit-tested via `useMobileBackButton.test.tsx`, not device-confirmed).

None of these four blockers were newly introduced by this sprint's changes — all four are pre-
existing environment limitations, already named in MN-1's and MN-2's own closeouts (for the fourth)
or in the July 2026 release-readiness/DUNS docs (for the first three).
